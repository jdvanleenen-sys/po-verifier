# Cold runs, 2026-11-03: messy inputs

Three new houses test the inputs a real painter will send: a handwritten phone photo, a phone
voice-memo transcript, and two photos (one sideways, glare over a number). Three fresh agents (Claude
Opus 5.5), one per house, each in a clean copy made by `tests/cold_run.py prepare`, with no answer
keys. The session that built the houses played Sam from `sam-answers.md`. Scored with
`tests/cold_run.py score`.

## What the reads got right, observed
- 14 Photo Close: read the doors as 13, not the crossed-out 12, and put it first on the list for Sam.
- 27 Voice Memo Way: read "I got for no wait 14 14 doors" as 14, and "thirty two sixty" as 3260.
- 36 Two Photos Lane: read both photos, turned the sideways one, zoomed in on the glare, read 19,
  and still asked Sam to confirm it.
- Every run listed each handwritten or spoken number as at risk and asked Sam to check it.
- Every money figure matched the key in all three houses.

## Found, not yet fixed
1. **The request cannot attach photo or voice notes.** `05 request/build_request.py` takes notes
   only as .txt or .md with "note" in the name, and `proof_spec` checks the notes by their first
   line of text. A .jpg is listed "not attached"; `voice-memo-transcript.txt` is not found at all.
   With Sam's "yes, attach them", the build stops. `01 intake/CONTEXT.md` allows photos, so the two
   stages disagree. Confirmed on 27 Voice Memo Way (exit 1, "Sam said attach his site notes, but
   there is no notes file in intake"). On the two photo houses Sam was moved to "don't attach" so
   the rest of the PDF step could be tested.
2. **Unit and meaning questions on every house.** All three runs asked whether railing and
   stringers are feet and whether square footage is floor area. A painter answers these the same
   way every time. Writing his standing answers into `reference/contractor.md` would remove three
   checks per house. Needs the painter's own words first.
3. **No read step for handwriting or voice.** `02 read` says nothing about photos (several pages,
   turned, glare) or machine transcripts (homophones, a correction mid-sentence). The agents
   handled them well on judgement; the folder should say how.
4. **A later plain yes after an earlier "I don't know"** is not covered. One run took it as
   approving the table as written, the others asked again.
5. **"Page 1 of 1" with proof pages after it** may confuse a site super.
6. **`CONTEXT.md` names `tests/`, which the tester copy leaves out.** Expected for a cold run, but
   the map should say so.

## Changes to the test, during the run (disclosed)
- Sam's scripted read-back answer was conditional ("If it matches ...: Yes"). The folder rightly
  refused a conditional yes, so each run needed an extra round. The three new houses now say a plain
  "Yes, to the whole table."
- 36 Two Photos Lane asked three things the script did not cover (which door row, units, floor
  area). The session playing Sam answered off script: 8' doors, feet, floor area. These are now a
  standing answer in all three new houses' `sam-answers.md`.

## Limit of this test
These runs used a copy of the folder from before the rule grid (`02 read/grid.py`) and
`03 compare/compare.py`. The houses still need a run on this branch, with the grid in the path.

The handwriting is a computer font made to look handwritten, on a clean page. A real painter's notes
will be harder. Sam was played from a script by the session that built the houses, and every agent
was the same model. A real painter's photos are the next test.
